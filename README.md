# ☕ Kopi Hening Landing Page

Website landing page modern untuk brand kopi **Kopi Hening** menggunakan React, Vite, TypeScript, dan Tailwind CSS.

---

## 🌐 Live Demo

🔗 https://kopi-hening.vercel.app

---

## 🚀 Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Lucide React

---

## ✨ Features

- Responsive Design
- Smooth Scrolling
- Hero Section
- Menu Section
- Gallery Section
- Contact Section
- Typing Animation
- WhatsApp Button
- Scroll Reveal Animation

## 📦 Installation

Clone repository:

```bash
git clone https://github.com/kptncici/Kopi-Hening.git
```

Masuk ke folder project:

```bash
cd Kopi-Hening
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open browser:

```bash
http://localhost:5173
```

---

## 🛠 Build Production

```bash
npm run build
```
