# ☕ Kopi Hening Landing Page

Website landing page modern untuk brand kopi **Kopi Hening** menggunakan React, Vite, TypeScript, dan Tailwind CSS.

## 🚀 Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Lucide React

---

## ✨ Fitur

- Responsive Design
- Smooth Scrolling
- Hero Section Modern
- Menu Section
- Gallery Section
- Contact Section
- Typing Animation
- WhatsApp Button
- Scroll Animation

---

```bash
src/

    └── cn.ts
```

---

## 📦 Installation

Clone repository:

```bash
git clone https://github.com/kptncici/Kopi-Hening.git
```

Masuk ke folder project:

```bash
cd Kopi-Hening
```

Install dependency:

```bash
npm install
```

Jalankan development server:

```bash
npm run dev
```

Buka browser:

```bash
http://localhost:5173
```

---

## 🛠 Build Production

```bash
npm run build
```
